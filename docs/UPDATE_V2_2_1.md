# Виправлення архіву та кошика — 2.2.1

У GitHub замініть папки `src`, `public`, `tests`, а також `package.json` і `package-lock.json`. Натисніть Commit changes і дочекайтеся зеленого результату останнього запуску Actions. Якщо V2 уже встановлена, нового SQL та змін Supabase/Vault не потрібно.

Новини, події, документи й послуги тепер архівуються/переміщуються до кошика через UPDATE, а не частковий UPSERT. При редагуванні існуючих матеріалів теж використовується UPDATE. Це зберігає поля, яких немає у формі.

У списку є «Активні записи», «Архів», «Кошик» і «Усі записи». Переміщені матеріали зникають з активного списку. Відновлення з архіву/кошика повертає матеріал як чернетку: для повторної публікації відкрийте Редагувати і виберіть Опубліковано.

Департаменти мають архів та відновлення через поле active. Зв’язки із послугами, заявами та зверненнями зберігаються. Видалення невикористаного департаменту працює. Якщо департамент або категорія використовується іншими записами, база захищає ці зв’язки; тепер показується зрозуміле повідомлення. Для департаменту використайте Архів, а для остаточного видалення спочатку перепризначте пов’язані записи.

Виправлено також часткове збереження профілю й аватара. Видалення без доступного запису більше не повідомляє про успіх. Правила RLS та права ролей не послаблювалися.
