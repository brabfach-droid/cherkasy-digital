# Нове табло — версія 2.2.0

## Як оновити GitHub

1. Розпакуйте ZIP.
2. Завантажте папку `src` в корінь свого репозиторію (де вже є `package.json`). Натисніть **Commit changes**.
3. Окремою загрузкою замініть `package.json` і `package-lock.json`. Натисніть **Commit changes**.
4. Окремо завантажте `public`, потім `tests` — остання папка потрібна для автоматичних перевірок workflow. Якщо GitHub обмежує кількість файлів, завантажуйте кожну папку окремо.
5. Дочекайтеся зеленого результату останнього запуску в **Actions**. Перезавантажте сайт.

У цьому архіві немає `dist`, `node_modules` і `test-results`: GitHub Actions збирає сайт сам. Якщо V2 вже встановлена, нового SQL та змін Vault не потрібно. Приватний `.env` не завантажуйте.

## Як запустити екран

Відкрийте `/display`. Ротація починається автоматично. Натисніть «Увімкнути повноекранний режим». Браузер вимагає натискання користувача для fullscreen; налаштування «Пропонувати повноекранний запуск» показує підказку, а не обходить це обмеження.

Після 3,5 секунди без руху курсор і панель запуску ховаються. Рух миші повертає їх. Екран підтримує Full HD, 1366×768, 1440p та 4K; внутрішній відступ 3,5vw враховує краї телевізора.

## Налаштування

В адмінпанелі відкрийте **Інформаційне табло** (`/admin/display`). Тут є перемикачі сцен, кнопки порядку, тривалість кожної сцени, 3–8 новин, 2–4 події, годинник, дата, QR, стрічка, фон, акцент, режим зображення та тип переходу.

Кнопка **Відкрити preview display** показує точний 1920×1080 preview у форматі 16:9. Він використовує поточні незбережені налаштування. Після зміни натисніть «Оновити preview», а для публікації — «Зберегти табло». Відкритий екран перечитує налаштування щохвилини.

Фото новин беруться з обкладинки матеріалу в медіатеці. Якщо обкладинки немає або вона не завантажилася, показується оформлена міська заставка. Новини, офіційні документи й послуги мають QR на свій матеріал/каталог.

## Тривога та дані

На початку тривоги — велике сповіщення на 7 секунд, потім знову звичайний контент. Червоний статус залишається у верхній смузі й дублюється в стрічці. Новини, події та оголошення продовжують ротацію. Підтверджений відбій показується 5 секунд. Критичні повідомлення додаються до ротації, а не блокують екран назавжди.

Кеш тривоги старший за 2 хвилини або мережева помилка означають невідомий стан, а не відбій. Джерело охоплює Черкаський район та Черкаську область. Налаштування alerts.in.ua, Edge Function і cron залишаються попередніми; це оновлення дизайну не виправляє відсутній серверний токен.

Міські дані перечитуються кожні 30 секунд; новини, події, документи, послуги та налаштування — кожні 60 секунд без reload. Вік даних показується чесно. Нуль повідомлень про транспорт не означає підтверджену справність транспорту.
