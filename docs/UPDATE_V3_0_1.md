# Оновлення V3 → 3.0.1

Це виправлення темної теми, підказка для зміни статусу заяви та виправлення збереження статусу звернення оператором. Якщо міграція V3 вже виконана з відповіддю `Success. No rows returned`, SQL повторно запускати не потрібно. Supabase, Vault, токен тривог і Secrets не змінюйте.

1. Розпакуйте архів.
2. На GitHub відкрийте свій репозиторій → Code → Add file → Upload files.
3. Замініть `src`, `package.json` та `package-lock.json` файлами з папки `cherkasy-digital`. Не завантажуйте сам ZIP або зайву зовнішню папку. У `src` менше 100 файлів; за потреби завантажуйте окремо підпапки.
4. Натисніть Commit changes. У Actions дочекайтеся зеленої галочки **Deploy GitHub Pages**.
5. Відкрийте сайт, натисніть Ctrl+Shift+R. У footer має бути `v3.0.1`.

## Статуси заяв

Це послідовні етапи. У розділі обробки заяви виберіть «Прийнято» та натисніть «Зберегти». Після цього з’являться «На розгляді», «Потрібна інформація», «Відхилено» та «Скасовано». Після «На розгляді» доступне «Схвалено», після «Схвалено» — «Виконано». Біля поля тепер є пояснення.

Зміна статусу виконується в робочому розділі працівника/адміністратора з відповідними правами. У власному кабінеті мешканець не може сам схвалити заяву.

## Статуси звернень

Виправлено помилку, через яку оператор звернень надсилав незмінений департамент разом зі статусом і отримував відмову через права на передачу. Тепер департамент надсилається лише при його зміні уповноваженим працівником.

Звернення мають окремі статуси: «Нове», «Прийнято», «Передано», «У роботі», «Виконано», «Відхилено».

## Темна тема

Виправлено світлі фони sidebar, таблиць, редактора, завантажувачів, історії, плашок статусів та кнопок налаштувань табло. Кольори статусів зберігають значення; текст і фони кнопок узгоджені, зокрема при наведенні. Біле поле QR збережене для читабельності коду. Вміст PDF має власне оформлення документа.
