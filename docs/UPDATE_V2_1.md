# Оновлення до 2.1.0

1. Розпакуйте архів.
2. У своєму репозиторії GitHub замініть файли з папки `cherkasy-digital`, зокрема `src`, `public`, `package.json` та `package-lock.json`. Завантажуйте вміст папки в корінь репозиторію.
3. Збережіть зміни через **Commit changes**.
4. Відкрийте **Actions** й дочекайтеся зеленого результату workflow публікації GitHub Pages.
5. Відкрийте сайт і перезавантажте сторінку. Непомітний номер версії має бути `v2.1.0`.

Якщо версія 2.0 уже встановлена, нових SQL-запитів і змін Vault для цієї переробки не потрібно. Якщо оновлюєте V1, спочатку виконайте `docs/UPDATE_V2.md`. Збережіть свої налаштування GitHub Secrets та `.env`; не завантажуйте приватні токени в репозиторій.

## Що змінилося

Тривога завжди доступна в header, зокрема на телефоні. Клік відкриває компактну панель із регіоном, початком, часом оновлення та переходом на `/now`. Важливе оголошення залишається окремою плашкою.

`/display` — нове міське табло: великий годинник за Києвом, плавний фон, великі модулі, стрічка повідомлень, QR та ротація сцен. Активна тривога або критичний статус зупиняє ротацію. Підтверджений перехід від тривоги до її відсутності показує відбій на 8 секунд.

Header, `/now` і `/display` використовують спільний потік даних: frontend перечитує базу кожні 30 секунд. Дані alerts.in.ua надходять через раніше налаштовану Edge Function і cron. Ця переробка не замінює налаштування токена чи синхронізації.

Кеш тривоги старший за 2 хвилини, помилка мережі або відсутність даних означають «Статус тривоги недоступний», а не «Тривоги немає». Помилка не створює відбій. Показується реальний вік даних, без фіктивного LIVE. Охоплення джерела: Черкаський район та Черкаська область.

Налаштування табло залишаються в адмінпанелі: увімкнення, інтервал, сцени й тема. Анімації враховують системне налаштування зменшення руху.
